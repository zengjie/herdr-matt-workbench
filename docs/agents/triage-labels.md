# Triage labels

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 已明确，可由 Agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不实施 |

Spec 由 to-spec 发布时使用 `ready-for-agent`，无需重复 triage。标签不证明实现、检查、人工验收或集成已完成。
