# Domain docs

本项目采用单领域资料布局。

- 讨论术语、设计、Spec 或实现前，读取根目录的 [GLOSSARY](../../GLOSSARY.md)。
- 行为与范围以 GitHub 上已发布 Spec 为准，本地 [Spec 快照](../design/2026-11-04-herdr-unified-workspace-spec.md)方便随代码阅读。
- 核对交互和责任边界时，读取 [当前设计基线](../design/2026-11-04-unified-workspace-baseline.md)。早期设计不覆盖新基线。
- 涉及工作流启用范围与工作区绑定时，读取 [ADR 0001](../adr/0001-opt-in-matt-workflow.md)。后续 ADR 与相关领域资料关联，实施前读取涉及的决策。
- 需要体验原型时，使用 `prototype/unified-workspace` 分支。它是一次性设计证据，不是生产模块。
